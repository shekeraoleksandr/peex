### BASIC OS CONFIGURATION — CREATE AND VERIFY A USER ACCOUNT
target : EC2 web instance 32.196.140.165 (Ubuntu 24.04)
user   : peexops
auth   : ed25519 key pair generated for this account specifically

===== BEFORE: the account does not exist =====

$ getent passwd peexops
Warning: Permanently added '32.196.140.165' (ED25519) to the list of known hosts.
(no such user — as expected)

===== APPLYING THE CONFIGURATION =====

$ useradd + sudo group + authorized_keys  (idempotent)
user created
ssh key installed

===== AFTER: the account exists, with the expected properties =====

$ getent passwd peexops; id peexops

uid=1001(peexops) gid=1001(peexops) groups=1001(peexops),27(sudo)

$ ls -la /home/peexops/.ssh   # permissions matter: sshd refuses loose modes
