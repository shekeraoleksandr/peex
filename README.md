# peex — рішення завдань по розділах

Кожен розділ — окрема папка з номером і назвою, напр. `01-<назва>`.
Структура кожного розділу однакова, тож перевіряючому легко зорієнтуватися.

## Як користуватися
1. Нове завдання → скопіювати `_template` у нову папку `NN-<назва>`.
2. Заповнити README (умова + як запустити + що доводить).
3. Покласти рішення в `src/`.
4. Запуск однією командою: `./run.sh` (або `docker compose up`).
5. Результат виконання зберегти в `proof/` (логи, вивід, скріншоти).

## Структура розділу
```
NN-<назва>/
  README.md      умова + інструкція запуску + що демонструється
  src/           сам код / рішення
  run.sh         одна команда для запуску та перевірки
  Dockerfile     (опціонально) ізольоване середовище
  proof/         докази виконання: логи, вивід тестів, скріншоти
```
